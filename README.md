# Rock Paper Scissors Game

This is a simple Rock Paper Scissors game built using HTML, CSS, and JavaScript.

The project was created as part of my web development learning journey to practice JavaScript logic, DOM manipulation, and event handling.

## Features

* Play against the computer
* Random computer choice generation
* Score tracking
* Instant result display
* Interactive user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## What I Learned

While building this project, I practiced:

* JavaScript fundamentals
* DOM manipulation
* Event handling
* Conditional statements
* Random number generation
* Creating interactive web applications

## How to Play

1. Choose Rock, Paper, or Scissors.
2. The computer will make a random choice.
3. The winner is decided according to the game rules.
4. Scores are updated automatically.

## About This Project

This project helped me understand how JavaScript can be used to create interactive games and handle user actions in real time.
